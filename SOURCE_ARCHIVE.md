# Архив исходников Шихши 1.3.0

В этой ветке сохранён исходный проект Expo из локального архива версии **1.3.0** (Android versionCode **5**). Разбор APK версии 1.9.0 находится в ветке [main](https://github.com/umaxan333/Shikhsha-Android/tree/main).

Установите зависимости через `npm ci`. Команда `npm run check` запускает проверку типов, линтер и тесты. Инструкции по запуску и сборке находятся в [README.md](README.md) и [docs/ANDROID_APK.md](docs/ANDROID_APK.md).

В архив не входят установленные зависимости, APK, локальные настройки Expo и файлы с ключами подписи. Для выпуска обновления существующей установки Android потребуется исходный ключ подписи.
