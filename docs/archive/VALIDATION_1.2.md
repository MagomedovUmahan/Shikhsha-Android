# Проверки проекта

Дата: 1 ноября 2026 года. Текущая версия: 1.2.0.

## Выполнено для 1.2

- `npm run typecheck`: TypeScript без ошибок.
- `npm run lint`: ESLint без ошибок и предупреждений.
- `npm test`: 18 тестов проходят. Восемь прежних тестов дат/статистики/настроек; восемь тестов GPS, расстояния, фильтрации, разрывов, пауз, шагов через полночь и GPX; два интеграционных сценария хранилища с настоящим SQLite через адаптер native bridge для Node.
- Интеграционные сценарии SQLite выполняют производственный SQL: единственная активная прогулка, повторные и параллельные пакеты без удвоения, пауза/продолжение, отсутствие перемычки между участками, rollback при ошибке, запрет удаления активной прогулки, завершение и удаление точек. Отдельно проверено прореживание 7 002 точек для карты с сохранением границ, полная детализация для GPX.
- `EXPO_OFFLINE=1 npx expo install --check`: зависимости соответствуют локальной таблице SDK 58. Это не онлайн-диагностика Expo Doctor.
- Чистый `expo prebuild --clean --platform all --no-install` в отдельной временной копии: Android и iOS генерируются. Проверены Android-разрешения FINE/COARSE/BACKGROUND_LOCATION и FOREGROUND_SERVICE_LOCATION; iOS background mode location и русские описания разрешений. LocationTaskService типа location объявлена модулем Expo Location. MapLibre добавляется config plugin.
- `expo export --platform all`: Metro создаёт веб-пакет и Hermes-пакеты Android/iOS. Веб использует отдельное хранилище-заглушку без SQLite/WASM; шаги и GPS не подделываются.
- Интерфейс проверен в Chromium: пять вкладок, переключатель фонового/foreground-режима, отключённый старт записи в браузере, возврат и перезагрузка страницы прогулки. Проверены прежние фильтры 30/90 дней, загрузка истории шагов, закрытые достижения, темы, сохранение и валидация настроек. На ширинах 320/390/768 нет горизонтального переполнения. Ошибок JavaScript не обнаружено.

Тесты SQLite используют адаптер к `node:sqlite`, а не настоящий телефонный Expo SQLite. Они подтверждают логику SQL и жизненного цикла хранилища; не подтверждают доставку фоновых событий ОС и работу native bridge.

## Android: полная сборка 1.2.0

- Выполнены `:app:assembleRelease` и `:shikhsha-pedometer:testDebugUnitTest` с `-PreactNativeArchitectures=arm64-v8a`. Gradle завершился с кодом 0, `BUILD SUCCESSFUL`: 972 задачи, 782 выполнены, 152 из кэша, 38 актуальны.
- Собственный модуль шагомера скомпилирован в Release/Debug. Шесть JUnit-тестов StepAccumulator: failures 0, errors 0, skipped 0. APK включает интеграции MapLibre, Expo Location, TaskManager и SQLite. Для части Expo SDK используются штатные предварительно скомпилированные AAR SDK 58.
- Инструменты: Corretto JDK 17.0.21, Gradle 9.4.1, Build Tools 37.0.0, compile SDK 37.0, target SDK 36, min SDK 24, NDK 27.1.12297006, CMake 3.22.1, Kotlin 2.2.10. Использована стандартная release-конфигурация с R8.
- APK `Shikhsha-1.2.0-android-arm64.apk`: 45 716 249 байт, версия 1.2.0, versionCode 4, пакет `app.shikhsha.pedometer`, имя «Шихша». `debuggable=false`; тестовая подпись Android Debug проверена `apksigner`, APK Signature Scheme v2 действительна.
- Проверены необходимые разрешения активности, уведомлений, точной/фоновой геопозиции, foreground-служб health/location. READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE и SYSTEM_ALERT_WINDOW отсутствуют.
- В APK есть встроенный Hermes-пакет JavaScript (2 630 888 байт) и 27 нативных библиотек ARM64, включая MapLibre и SQLite. Архив APK проходит CRC-проверку. `zipalign -c -P 16 4` проходит; все ELF PT_LOAD имеют выравнивание не меньше 16 КиБ.
- SHA-256 APK: `d8e81f6b129b2ff07dd302a1e3799adecfc4de9424aa46e51aa7ac5bc254a539`.

Машиночитаемый результат проверки файла — в `ANDROID_BUILD.json`. Предупреждения зависимостей об устаревших Gradle API остаются; они не остановили сборку. Тестовый APK распространяется отдельно от архива исходников и не является публикацией в магазине.

## Оставшаяся проверка на устройствах

APK не устанавливался и не запускался на физическом телефоне: проверен файл и результат компиляции. Сборка IPA не выполнялась; новый Swift-запрос шагов за интервал не проверен Xcode. Android-сборка не подтверждает работоспособность iOS.

Нужны физические Android и iPhone для проверки сенсора, разрешений, точности маршрута, системной доставки GPS в фоне, блокировки экрана, убийства процесса, расхода батареи, карты, GPX через меню отправки и удаления. Конкретные сценарии — в `TESTING.md`.

Инструкция установки отдельного APK — в `ANDROID_APK.md`. До установки и приёмки GPS, фоновой записи и аппаратного счётчика нельзя считать приложение проверенным на конкретной модели телефона. Сборка описана в README; Expo Go эти функции не содержит.
