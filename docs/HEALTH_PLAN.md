# Модель плана активности

Это настраиваемый ориентир приложения для взрослых, не медицинское назначение, не измерение жировой массы и не обещание похудения. Потребности поддержания веса различаются. Питание, сон, заболевания, лекарства и другие нагрузки не оценены.

Базовые входы: текущий вес 30–300 кг, выбранная цель, привычные шаги 1 000–30 000 в день. При наличии записанных дней можно подставить их среднее; отсутствие дней не подменяется вымышленной активностью.

Модель выбирает 150 мин/нед. для режима «Поддержание» и 300 мин/нед. для «Похудения». CDC указывает 150 минут как базовую рекомендацию умеренной активности для общего здоровья, а не достаточный для любого человека объём поддержания веса. NIDDK отмечает, что для снижения/удержания веса может понадобиться 300 минут и больше. Поэтому в приложении это явно названо планом, а не нормой или точной потребностью.

Условный перевод: `extraSteps = round((weeklyMinutes / 7 × 100) / 250) × 250`. `dailyGoal = baselineSteps + extraSteps`. 100 шагов/мин — исследовательская эвристика интенсивности для части взрослых; фактический темп/интенсивность каждого пользователя не измеряются. Нельзя считать выполнение числа шагов подтверждением выполнения нормы умеренной активности. Если исходные шаги уже включают такую ходьбу, цель нужно скорректировать вручную.

Вес не определяет шаговую цель: два человека с разным весом и одинаковыми исходными условиями получают один ориентир шагов. Вес нужен для отдельной приблизительной оценки энергии: `netKcal = (3.8 − 1) × weightKg × (distanceKm / 4.8)`, где `distanceKm = steps × strideCm / 100000`. Предполагается ровная ходьба 4,8 км/ч, 3,8 MET (Compendium, код 17190), с вычетом 1 MET покоя. Это расчётная модель, не расход энергии, измеренный датчиком. Для прошлых дат калории по текущему весу не показываются.

Для постепенного начала показывается уровень `baselineSteps + 500`, ограниченный итоговым ориентиром. Это правило интерфейса, не доказанный медицинский темп увеличения нагрузки. Пользователь сам регулирует цель и нагрузку; при ограничениях нужна индивидуальная консультация.
