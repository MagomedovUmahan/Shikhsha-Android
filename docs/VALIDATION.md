# Проверки Шихши 1.3 / EAGLE VISION

Дата: 4 ноября 2026 года. Основной сценарий текущей версии — Expo Go на iPhone.

## Выполнено

- TypeScript проходит, ESLint без ошибок и предупреждений после исправления дублирующего импорта.
- 29 тестов JavaScript/TypeScript проходят: прежние 18 для активности, статистики, GPS/GPX и SQLite; 6 для счётчика Expo Go; 5 для профиля, модели плана и личного индекса.
- Счётчик Expo Go: не импортирует шаги до первого старта и во время паузы; закрытые интервалы сохраняются после перезапуска; включённый интервал восстанавливается запросами истории; полночь разбивается по локальным дням; поздние события старой подписки игнорируются; отказ в разрешении, ошибка записи и повреждённая история не считаются успешным стартом.
- Дополнительно 15 тестов активности/профиля/Expo-счётчика выполнены с TZ=America/Los_Angeles; проходят.
- `EXPO_OFFLINE=1 npx expo install --check`: зависимости соответствуют локальной таблице SDK 58. Это не онлайн-проверка Expo Doctor.
- `expo export --platform all`: успешно сформированы веб-пакет и Hermes-пакеты Android/iOS.
- Реально запущен Metro в режиме `expo start --go --localhost`; получен iOS-манифест Expo Go для SDK 58.0.0, версии 1.3.0. По launchAsset URL успешно получен iOS JavaScript-пакет (около 6,8 МБ для development-режима), содержащий адаптер Expo Pedometer и Apple Maps. Прямые запросы иконки PNG и шрифта Ionicons возвращают HTTP 200. В среде проверки CLI также выводил предупреждение о прерванной подготовке ресурсов манифеста; наличие и выдача самих файлов подтверждены отдельно.
- Chromium, 390 × 844: пять вкладок; ввод веса с точкой/запятой, отклонение некорректного веса, переключение «Поддержание»/«Похудение», расчёт 7 250/9 250 при базе 5 000, сохранение после перезагрузки, ручная корректировка цели с сохранением профиля, удаление профиля. Проверены светлая/тёмная темы, виртуальные звания и отсутствие поддельных шагов. На ширинах 320/390/768 нет горизонтального переполнения. Ошибок JavaScript нет.
- Визуально просмотрены главная страница в двух темах и форма плана. Орёл, горы и орнамент — собственные SVG-компоненты, иконка приложения растрирована из собственного SVG.

Тесты Expo-счётчика используют управляемый адаптер Core Motion, а SQLite-тесты — настоящий SQLite Node через адаптер native bridge. Это проверяет логику, но не аппаратный сенсор/геолокацию конкретного iPhone.

## Что не подтверждено

Физический iPhone не подключён: сканирование QR пользователем, запросы разрешений на его телефоне, Apple Maps, реальная точность шагов/GPS, время доставки событий, экспорт через системное меню и расход батареи ещё требуют приёмки. Серверный тест манифеста и пакета не является запуском приложения на iOS-устройстве.

Новый Swift-код активных интервалов для отдельной iOS-сборки не компилировался Xcode. Новые APK/IPA версии 1.3 не создавались. Успешная Android-сборка 1.2 и её шесть нативных тестов — историческая проверка; отчёт сохранён в `archive/VALIDATION_1.2.md`, параметры APK — в `archive/ANDROID_BUILD_1.2.json`. Старый APK 1.2 не содержит изменений 1.3.

Фоновый GPS в Expo Go на iPhone не поддерживается этой реализацией: переключатель отключён, прогулка работает с открытым приложением и автоматически ставится на паузу при сворачивании. Дневные шаги могут дочитываться из системного кэша при возвращении, если счётчик был включён.
