# iPhone + Expo Go: запуск с Windows

1. Установи Node.js 24 LTS на компьютер. Установи или обнови Expo Go в App Store на iPhone.
2. Полностью распакуй архив. Открой папку `shikhsha` с файлом `package.json`. Запуск прямо внутри ZIP не подходит.
3. Открой терминал в этой папке и выполни:

```bash
npm ci
npm run iphone
```

Можно запустить `START_IPHONE.bat` двойным нажатием. Не закрывай окно терминала во время проверки приложения.

4. Подключи iPhone и компьютер к одной Wi-Fi-сети. Камерой iPhone отсканируй QR-код из терминала и выбери открытие в Expo Go. Разреши доступ к локальной сети, если iOS предложит.
5. В Шихше нажми «Начать считать шаги», разреши движение и фитнес. Датчик может выдать обновление с задержкой. Данные до первого включения счётчика не добавляются.
6. Нажми «Пауза», пройди несколько шагов, затем «Продолжить». История должна сохраниться, шаги паузы не должны прибавиться. Системный iPhone продолжает свой собственный подсчёт; Шихша читает только активные интервалы.
7. Во вкладке «Опции» укажи вес, обычную активность и выбери цель. Посмотри расчёт и нажми «Применить план».
8. Для маршрута открой «Прогулка», нажми старт и разреши точную геопозицию при использовании приложения. Карта Apple Maps появится после первой достаточно точной GPS-точки. Держи приложение открытым во время GPS-прогулки.

## Если QR не открывается

Останови прежний сервер Ctrl+C и запусти:

```bash
npm run iphone:tunnel
```

Дождись нового QR-кода. Туннель требует доступного ngrok. Если iPhone предлагает доступ к локальной сети, его нужно разрешить для LAN-запуска. В сетях с изоляцией устройств LAN-соединение может быть недоступно.

Если Expo Go сообщает, что SDK не поддерживается, обнови Expo Go. Проект рассчитан на SDK 58. Не меняй вручную только номер `expo` в package.json: версии React Native и native-библиотек должны соответствовать SDK.

`npm run ios` запускает компиляцию через Xcode на Mac. Для запуска через Expo Go на Windows эта команда не нужна.

## Ограничения Expo Go на iPhone

- Маршрут при блокировке экрана и сворачивании приложения автоматически ставится на паузу. Для фонового GPS нужна отдельная iOS-сборка с разрешениями приложения.
- Шаги при включённом дневном счётчике можно дочитать из Core Motion при возвращении; доступность истории ограничена системным кэшем около 7 дней.
- Во время ручной паузы шаги в Шихшу не добавляются. Закрытый активный интервал может быть дочитан до сохранённого момента паузы.
- Показания телефона могут отличаться от Apple Health, объединяющего часы и другие источники.
- Профиль и история находятся на телефоне в данных проекта Expo Go. Удаление/очистка Expo Go может их удалить. Разработческие данные могут отличаться от отдельного приложения.

На физическом iPhone запуск, разрешения и точность датчика ещё нужно проверить пользователю: здесь проверены код, модель активных интервалов, сборка JavaScript и сервер Expo Go, а не аппаратный датчик конкретного телефона.
