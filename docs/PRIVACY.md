# Данные Шихши 1.3

Шихша не требует аккаунта, не содержит рекламы и собственного сервера для профиля, истории шагов или маршрутов.

- Вес, цель и привычная активность сохраняются в AsyncStorage на телефоне. Кнопка «Удалить вес и профиль» удаляет профиль из настроек; ручную дневную цель можно оставить. История веса не собирается.
- В Expo Go на iPhone дни шагов и границы активного интервала сохраняются в AsyncStorage. В отдельных сборках шаги находятся на нативной стороне: SharedPreferences/UserDefaults. Читается движение телефона через Core Motion/датчик, не объединённый аккаунт Apple Health.
- Прогулки находятся в локальной SQLite: координаты, время, качество принятых точек, доступная высота, интервалы и показатели. Завершённые прогулки не удаляются автоматически; доступно удаление каждой прогулки с подтверждением.
- Геопозиция запрашивается только при явном старте прогулки. На паузе/после завершения подписка прекращается. В Expo Go на iPhone доступна запись при открытом приложении; отдельные сборки могут использовать фоновый доступ для текущей прогулки.
- Expo Go на iPhone использует Apple Maps, отдельные сборки — MapLibre с OpenFreeMap. Провайдер карты получает сетевые запросы отображаемой области и может кэшировать ресурсы. Это не локальная офлайн-карта. Атрибуция SDK сохраняется.
- При разработке Expo Go получает JavaScript/ресурсы проекта с сервера Metro на компьютере. При туннеле соединение проходит через ngrok. Сам хост Expo Go является отдельным приложением со своей политикой данных.
- GPX создаётся по выбранной пользователем команде и содержит точные координаты/время. Получателя выбирает пользователь в системном меню. Временный файл остаётся в кэше для чтения принимающим приложением и удаляется вместе с прогулкой или при очистке кэша. Отправленная копия остаётся у получателя.
- Удаление приложения/данных Expo Go может стереть локальную историю. Системная история движения телефона и отправленные GPX живут отдельно. Экспорт профиля или облачная синхронизация не реализованы.

Это описание текущей реализации. Политика для публикации должна соответствовать фактической сборке, провайдерам карт и каналам распространения.
