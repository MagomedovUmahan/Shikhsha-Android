# Шихша / EAGLE VISION 1.3

Шагомер на React Native, Expo SDK 58 и TypeScript. Кавказская эстетика и современные технологии: горные силуэты, авторский геометрический орнамент, орёл, чёрный/серебристый и холодный зелёный. Реальные данные телефона; демонстрационных шагов и маршрутов нет.

## Запуск на своём iPhone через Expo Go

На компьютере установи Node.js 24 LTS. Распакуй проект и открой терминал в папке `shikhsha`, где находится `package.json`:

```bash
npm ci
npm run iphone
```

На Windows можно дважды нажать `START_IPHONE.bat`: он установит зависимости, если их ещё нет, и запустит эту же команду.

1. Установи или обнови Expo Go на iPhone из App Store.
2. Подключи компьютер и iPhone к одной Wi-Fi-сети.
3. Отсканируй QR-код из терминала камерой iPhone и открой ссылку в Expo Go.
4. Разреши Expo Go доступ к локальной сети, если iOS спросит. Нажми «Начать считать шаги» и разреши «Движение и фитнес».
5. Во вкладке «Опции» укажи вес, привычную активность и цель. «Применить план» сохранит профиль и выбранный ориентир по шагам.

Если QR-код не открывается по Wi-Fi, останови сервер Ctrl+C и попробуй туннель:

```bash
npm run iphone:tunnel
```

Клиент туннеля включён в зависимости. Его доступность зависит от сети и сервиса ngrok. Для обычного запуска на одной Wi-Fi-сети туннель не нужен. Более подробная инструкция — `docs/IPHONE_EXPO_GO.md`.

`npm run ios` предназначен для компиляции отдельного iOS-приложения на Mac с Xcode. Для Expo Go на Windows используй `npm run iphone`.

## Возможности

- Шаги, дневная цель, история до 90 записанных дат, статистика за 7/30/90 календарных дней.
- Пауза и продолжение счётчика с сохранением истории. Шаги паузы после продолжения не прибавляются.
- Вес 30–300 кг, цели «Поддержание»/«Похудение», привычное число шагов, прозрачный ориентир активности и приблизительная энергия ходьбы.
- Реальная карта маршрута, GPS-расстояние, время без пауз, темп, скорость, сохранение прогулки в SQLite и экспорт GPX.
- Пять вкладок, тёмная/светлая/системная темы, виртуальные вершины и звания «Исследователь», «Горец», «Покоритель вершин».
- Личный индекс активности по собственным записанным дням, без вымышленного рейтинга других людей.

## Expo Go и отдельные сборки

| Среда | Шагомер | Карта | GPS при блокировке |
| --- | --- | --- | --- |
| Expo Go на iPhone | Expo Pedometer / Core Motion, реальные интервалы | Apple Maps | Нет; прогулка ставится на паузу |
| Отдельная Android-сборка | TYPE_STEP_COUNTER, нативная foreground-служба | MapLibre + OpenFreeMap | При выданном фоновом доступе и работающей службе |
| Отдельная iOS-сборка | Собственный Core Motion-модуль | MapLibre + OpenFreeMap | Требует отдельной сборки и разрешения «Всегда» |
| Браузер | Нет; только интерфейс | Состояние без записи | Нет |

В Expo Go на iPhone оставляй приложение открытым для записи маршрута. При сворачивании/блокировке GPS-прогулка остаётся на паузе до ручного продолжения. Дневной шагомер может дочитать доступные системные шаги при возврате из фона, если сам счётчик не был поставлен на паузу.

Версия 1.2.0 ранее собрана в отдельный Android APK. Этот старый APK не содержит изменения 1.3. Для текущей версии основной способ запуска на iPhone — Expo Go; новые APK/IPA в этом архиве отсутствуют.

## Как работает пауза

Android отключает подписку на датчик и очищает его базу отсчёта, сохраняя дневные значения. После продолжения первая новая аппаратная величина становится новой базой.

В Expo Go на iPhone сохраняются начало активного интервала, дневная база и точное время паузы. Запросы Core Motion ограничены этим интервалом. После продолжения открывается новый интервал, поэтому шаги паузы не импортируются. Пауза хранится в AsyncStorage и переживает перезапуск проекта. Нативный iOS-модуль использует аналогичную схему в UserDefaults.

Пауза счётчика сначала приостанавливает активную GPS-прогулку, если она есть. Продолжение дневного счётчика не возобновляет GPS автоматически: прогулку продолжи на её экране.

iPhone хранит доступные запросам Core Motion данные примерно за последние 7 дней. Более старые неизвестные интервалы не восстанавливаются. Сохранённые ранее дневные значения остаются в истории. Это данные движения телефона, а не объединённые Apple Health/Apple Watch.

## Вес и цель

Вес сам по себе не определяет норму шагов и не позволяет обещать похудение. Шихша предлагает настраиваемую модель активности для взрослых:

- для «Поддержания» модель использует 150 минут целевой ходьбы в неделю;
- для «Похудения» — 300 минут;
- условный перевод — 100 шагов в минуту, округление до 250 шагов, плюс указанная привычная активность;
- мягкий старт — на 500 шагов больше привычного уровня, с постепенным увеличением по самочувствию.

Например, база 5 000 даёт ориентиры 7 250 и 9 250 шагов. Если привычные шаги уже включают целевую ходьбу, скорректируй цель вручную. Вес влияет на оценку энергии, а не искусственно увеличивает количество шагов. Питание, темп, здоровье и другие нагрузки влияют на результат; приложение не прогнозирует потерянные килограммы или срок похудения. Основания и ограничения — `docs/HEALTH_PLAN.md`, они также доступны в форме плана.

## Разработка и проверки

```bash
npm run check
npm run web
npx expo export --platform all
```

Данные браузерной версии не являются имитацией датчика. Шагомер и маршрут нужно проверять на физическом телефоне. Выполненные проверки — `docs/VALIDATION.md`, сценарии приёмки — `docs/TESTING.md`.

Для отдельной сборки с собственными native-модулями:

```bash
npm run android -- --device
# Только macOS с Xcode:
npm run ios -- --device
# Metro для установленной development-сборки:
npm run start:dev-client
```

Можно использовать `eas.json` через Expo Services (`npx eas-cli@latest build --platform android --profile preview`); потребуется собственная учётная запись и подпись. Генерируемые корневые `android/` и `ios/` в архив не входят. Не правь их вручную: нативный код приложения находится в `modules/`, конфигурация — в `app.json`.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/app/` | Пять вкладок и карточка прогулки, Expo Router |
| `src/components/Caucasus.tsx` | Векторные горы, орёл и орнамент |
| `src/components/GoalPlanner.tsx` | Вес, цель, расчёт и применение плана |
| `src/lib/goals.ts` | Проверяемая логика плана и оценки энергии |
| `src/lib/expoCounter.ts` | Счётчик активных интервалов для Expo Go на iPhone |
| `src/state/` | Состояние активности, тем, прогулок |
| `src/tracking/` | GPS-фильтр, SQLite, GPX, фоновая задача для отдельных сборок |
| `modules/shikhsha-pedometer/` | Собственные Android/iOS-модули |
| `docs/` | Запуск, ограничения, приёмка, приватность |

Данные профиля, шаги и маршруты хранятся локально. Удаление приложения может удалить их; GPX можно экспортировать отдельно. Карты и сервер разработки используют сеть. Подробности — `docs/PRIVACY.md`.
