# Шихша для Android — разбор версии 1.9.0

Шихша — приложение для отслеживания шагов и прогулок. Этот репозиторий собран по Android APK версии 1.9.0 (код версии 13, пакет `app.shikhsha.pedometer`).

[Скачать APK 1.9.0](https://github.com/umaxan333/Shikhsha-Android/releases/download/v1.9.0/Shikhsha-1.9.0-Android.apk) · [Страница релиза](https://github.com/umaxan333/Shikhsha-Android/releases/latest) · [Посмотреть архитектуру](docs/architecture.md)

Для установки откройте скачанный APK на телефоне с Android 7.0 или новее.

Оригинальный проект Expo версии 1.3.0 сохранён в отдельной ветке [source/1.3.0](https://github.com/umaxan333/Shikhsha-Android/tree/source/1.3.0).

- [Технический разбор](docs/architecture.md): слои приложения, разрешения, хранение и ограничения восстановления.
- [Инвентарь APK](docs/inventory.json): все записи архива, размеры, DEX и нативные библиотеки.
- [Восстановленный код Android](recovered/android): стартовые классы приложения, модуль шагомера, сервис, база данных, виджеты и логика восстановления.
- [Манифест](recovered/AndroidManifest.xml) и [ресурсы приложения](recovered/resources): декларации компонентов, графика, макеты и конфигурация виджетов.
- [Инструкция по повторению разбора](docs/reproduce.md) и [CLI](tools/inspect_apk.py) для инвентаризации и проверки на типовые секреты.

Java в `recovered/` сгенерирован декомпилятором. Это материал для чтения и восстановления проекта. Для сборки и выпуска нужны исходники React Native, настройки Expo/Android и зависимости исходного проекта. Имя пакета и версия не дают возможности выпустить обновление под прежней подписью.

Готовый APK доступен в разделе Releases. В Git не хранятся двоичные библиотеки, байткод Hermes, ключи подписи и полный сгенерированный дамп зависимостей. Локальный разбор не требует запускать APK.
